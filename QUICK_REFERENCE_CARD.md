# PocketWorth Enhanced Features - Quick Reference Card

## 🚀 Quick Start (5 Minutes)

### Step 1: Set Your Preferences
1. Tap **Settings** (gear icon)
2. Select **Currency** → Choose NPR (or your preference)
3. Toggle **Dark Mode** (optional)

### Step 2: Create a Budget
1. Tap **Budgets**
2. Click **+** button
3. Select category (e.g., "Food & Dining")
4. Enter budget limit (e.g., ₨5000)
5. Tap **Create Budget**

### Step 3: Track Subscriptions
1. Tap **Subscriptions**
2. Click **+** button
3. Select Netflix/Spotify (or type custom)
4. Enter amount (₨599)
5. Select cycle (Monthly/Yearly)
6. Tap **Add Subscription**

### Step 4: Get AI Insights
1. Tap **AI Advisor**
2. Click a suggestion or type a question
3. Get instant financial advice

### Step 5: Export Your Data
1. Tap **Settings** → **Export Data**
2. Choose period (Month/Year/All)
3. Download as CSV or JSON

## 💡 Feature Overview

### Budget Management
**What**: Set spending limits by category  
**How**: Dashboard → Budgets → Create  
**Why**: Track expenses against goals  
**Benefit**: Visual alerts when overspending  

### Subscription Tracker
**What**: Monitor recurring payments  
**How**: Dashboard → Subscriptions → Add  
**Why**: See monthly subscription costs  
**Benefit**: Find and cancel unused services  

### AI Advisor
**What**: Get personalized financial advice  
**How**: Dashboard → AI Advisor → Ask question  
**Why**: Optimize spending and savings  
**Benefit**: Data-driven recommendations  

### Data Export
**What**: Download financial records  
**How**: Settings → Export Data → Choose format  
**Why**: Backup and analysis  
**Benefit**: CSV for Excel, JSON for integration  

### Currency Support
**What**: Track finances in 10 currencies  
**How**: Settings → Currency → Select  
**Why**: International financial management  
**Benefit**: See conversion rates instantly

## 📊 Understanding the Numbers

### Financial Health Score
```
80-100: 🟢 Excellent  (Great savings rate, on-budget)
60-79:  🟢 Good       (Solid habits, room to improve)
40-59:  🟡 Fair       (Needs attention, some concerns)
0-39:   🔴 Needs Help (Urgent improvements needed)
```

### Savings Rate Target
```
Current Rate: (Income - Expenses) / Income × 100%
Target: 20% or higher
Less than 10%: Try to reduce non-essential spending
```

### Budget Status
```
0-75%:   ✅ On Track      (Green)
75-99%:  ⚠️  Approaching  (Yellow)
100%+:   ❌ Over Budget   (Red)
```

## 🆘 Troubleshooting Quick Fixes

| Problem | Solution |
|---------|----------|
| Budget not updating | Ensure transactions have dates and categories |
| Subscriptions showing wrong | Edit subscription details in the app |
| AI Advisor not responding | Try simpler questions, local AI always works |
| Export not downloading | Check browser settings, disable pop-up blocker |
| Currency not changing | Refresh app after selecting new currency |
| Dark mode not applying | Sign out and sign back in |
